MPI datatypes and operations

Detailed Description

Specify supported MPI datatypes and provide tools to simplify the creation of user-defined MPI types and operations.

The following functionality is provided:

  • mpi::mpi_type and its specializations let mpi know that a certain C++ type T can be used in MPI communications. The user is allowed to implement their own MPI compatible types and provide a specialization of mpi::mpi_type. Its static member function get maps the C++ type T to its corresponding MPI datatype.
  • mpi::has_mpi_type checks if a given type has a corresponding MPI datatype.
  • For aggregate types, providing a free function tie_data that returns a std::tuple of the data members is enough to make the type MPI-compatible: a specialization of mpi::mpi_type is then synthesized automatically (see Example 3: Custom type and operator). Internally this uses mpi::get_mpi_type, which builds an MPI_Datatype from a std::tuple via MPI_Type_create_struct.
  • mpi::map_add and mpi::map_C_function can help the user to implement custom MPI operations.

See Example 3: Custom type and operator for a detailed example.

nodiscard

#include <mpi/datatypes.hpp>

Create an MPI_Datatype from a serializable type.

It is assumed that the type has a member function serialize which feeds all its class members into an archive using the operator&.

// type to use for MPI communication
struct foo {
double x;
int y;
void serialize(auto& ar) const { ar & x & y; }
void deserialize(auto& ar) { ar & x & y; }
};

template<typename... Ts>
MPI_Datatype mpi::get_mpi_type ( std::tuple< Ts... > tup)
nodiscard

#include <mpi/datatypes.hpp>

Create a new MPI_Datatype from a tuple.

The tuple element types must have corresponding MPI datatypes, i.e. they must have mpi::mpi_type specializations. It uses MPI_Type_create_struct to create a new datatype consisting of the tuple element types.

The success of MPI calls is checked with mpi::check_mpi_call.
